02 / A METHODICAL MINDSET

Find the cause.
Make it clear.

Good support starts with listening. I like understanding what has gone wrong, looking up what I don't know and breaking the problem into manageable steps.

01 Understand the problem first.

02 Check one thing at a time.

03 Explain it without the jargon.

INTERACTIVE WALKTHROUGHIllustrative

“My computer won't get online.”

Start with the scope of the problem. What would you check?

NARROW IT DOWN / DEVICE

Start with the local connection.

If other devices work, check whether this PC is connected to the expected network and whether its cable or Wi-Fi connection is active. Change one thing, then test again.

A sample of structured thinking, not a live diagnostic tool or a completed client case.
